# Polish update

This pass is display-only and preserves the scoring rules.

## Changes

- Leader card shows `Open` before the first completed contest.
- After scoring starts, the Leader card shows `2-way tie`, `3-way tie`, etc. when top totals are tied.
- Local import notice now says imports are `active on this device only`.
- Scoring Detail and Locked Picks table headers use compact contest labels for repeated labels, such as F3/F4/F5 instead of repeating `Main Card`.
- User-side fastest finish prop is labeled `Predicted fastest finish` because it is derived from method/round picks.
